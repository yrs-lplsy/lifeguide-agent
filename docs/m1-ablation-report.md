## 结论/建议（M1 管线定稿）

**最终 M1 管线：维持 D_3way_rerank（三路融合 + rerank）**。E 组 recall@5 0.8475 低于 D 组 0.8559（-0.0085，超过 0.005 噪声阈）：尽管融合层在 rerank 前为负贡献（B−A、C−B），融合候选池经 rerank 后对 recall 仍是净增益——融合池的组成（扩池与成分变化）改变了 reranker 的输入，E 组完全 miss 而 D 命中的 4 条在 D 组均被送回 top-5，融合层保留。须如实记录的混合结果：精度类指标 E 反超（MRR 0.8662 vs 0.8560、nDCG@10 0.8197 vs 0.8094），即融合换来召回、损失排序精度；且该 recall 差与含稀疏路径的跨轮波动同量级，置信度中等。M1 以 recall@5 为主指标且 D 领先超阈，故取 D；E_dense_rerank 作为更简、更快（免 BM25 建索引/稀疏检索/RRF）的候选保留在 CONFIGS，M2 语料或查询分布变化时优先复测。
支撑数字：dense 上单加 rerank（E−A）recall@5 +0.0113 / MRR +0.0450；rerank 之上再叠加三路融合（D−E）recall@5 +0.0085 / MRR -0.0102 / nDCG@10 -0.0103；E vs D 逐查询（recall@5）：2 好 / 4 差 / 171 平。口径提示：含稀疏路的组（C/D）受 pgvector HNSW 近邻搜索影响存在跨轮波动（上一轮 C 组 recall@5 0.7853 → 本轮 0.7797，A/B 逐位复现），0.005 量级以内的组间差应视为噪声。
融合的诚实叙事：rerank 前融合各层均为负贡献（B−A、C−B），rerank 后才翻正为小幅净增益（D−E）——收益并非来自融合排序本身，而来自融合候选池的组成改变了 reranker 的输入；这一「先伤召回、靠重排捞回」的机制是本轮消融的核心发现。
